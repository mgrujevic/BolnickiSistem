# BolnickiSistem
Projekotavanje i implementacija  informacionog sistema za upravljanje elektronskim zdravstvenim kartonima pacijenata


## Pokretanje aplikacije

Klonirati repozitorijum i otvoriti projekat u Visual Studio-u.

Pre prvog pokretanja potrebno je podesiti connection string u fajlu:

`appsettings.json`

Connection string treba prilagoditi lokalnoj SQL Server instalaciji.

Nakon podešavanja connection string-a pokrenuti aplikaciju u Visual Studio-u (napomena projekat je verzije .net 10.0).
